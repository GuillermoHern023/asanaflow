🔄 Option 2: Live 2-Way Google Calendar API Sync (OAuth 2.0)

Disconnected

Connect directly to the Google Calendar API from your browser on GitHub Pages. Read your upcoming Google Calendar events and push task deadlines directly to your calendar with 1 click.

📖 How to get a free Google OAuth Client ID for your GitHub Pages URL (2 mins)
  1. Go to the Google Cloud Console — Google Calendar API and click Enable.
  2. Go to APIs & Services → Credentials → Create Credentials → OAuth client ID (Application type: Web application).
  3. Under Authorized JavaScript origins, add your GitHub Pages domain: https://guillermohern023.github.io (and http://localhost:8080 for local testing).
  4. Copy your Client ID (ends with .apps.googleusercontent.com), paste it above, and click Save & Connect with Google!
